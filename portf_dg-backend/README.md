
# Portfolio Backend

A backend service for managing portfolio data including contacts, projects, and blogs.

## Features

- Contact management
- Project tracking
- Blog content management

## Getting Started

### Prerequisites

- Node.js (v14+)
- npm or yarn

### Installation

```bash
npm install
```

### Running the Server

```bash
npm start
```

## Database Tables

| Table | Purpose |
|-------|---------|
| contacts | Store contact information |
| projects | Manage portfolio projects |
| blogs | Store blog posts |

## API Endpoints

- `/api/contacts` - Contact operations
- `/api/projects` - Project operations
- `/api/blogs` - Blog operations
